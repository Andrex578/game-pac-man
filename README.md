## 📖 Sobre o Projeto
O objetivo deste projeto é recriar a experiência clássica do Pac-Man diretamente no navegador (ou ambiente desktop). O jogador controla o Pac-Man através de um labirinto, com o objetivo de comer todas as pílulas para avançar de fase, enquanto evita ser capturado pelos fantasmas.

---

## ✨ Funcionalidades
- 🎮 **Controle de Movimentação**: Navegação fluida pelo labirinto usando o teclado.
- 👻 **Comportamento dos Fantasmas**: Fantasmas com padrões de movimentação e perseguição.
- ⚡ **Power Pellets (Super Pílulas)**: Permite ao Pac-Man comer os fantasmas temporariamente.
- 🏆 **Sistema de Pontuação e Vidas**: Acompanhamento de score atual e quantidade de vidas restantes.
- 🔄 **Game Over & Reinício**: Tela de término de jogo e opção de reiniciar a partida.
